- Lint and type-check on every push
- Run the build with `npm run build`
- Deploy previews for each pull request

```yaml
name: CI
on: [push]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm ci && npm run lint && npm run build
```
